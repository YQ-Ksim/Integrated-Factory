# Integrated Factory

Integrated Factory 是一个面向 Create 的 NeoForge 附属模组。它把一套机械动力工厂封装为一个可管理的“机器节点”：主世界负责线路组织、共享库存和应力结算，隔离机器空间继续使用真实的 Create 方块、配方、物流和动力网络进行加工。

当前版本：`2.5.1`  
目标环境：Minecraft Java `1.21.1`、NeoForge `21.1.x`、Create `6.0.10`

## 核心特点

- 每个节点拥有独立的 10×10×10 机器空间，多个工厂互不干扰。
- 主世界和机器空间访问同一份输入/输出库存，不通过定时复制物品实现同步。
- 应力端口接入 Create 的真实动力网络，按远端机器网络的实际应力负载进行桥接。
- 支持节点所有者、协作者、备注、进入、删除和重新绑定。
- 核心及简单集成单元的绑定信息会随掉落物保留。
- 核心不能由蓝图大炮打印、不能紧邻已有机器结构放置，也不能被活塞或 Create 动态结构移动；多核心冲突会保留绑定掉落物并保护原节点。
- 蓝图大炮只允许向当前机器空间的 10×10×10 建造区域打印；越界目标会在 Create 从容器抽取材料前直接跳过，不生成越界方块。
- 拓展接口不会把两个已成型结构强行合并；简单集成单元是独立节点，不参与大型结构的核心冲突判定。
- 潜行右键核心会显示节点摘要及对应的可点击管理行，可直接进入、删除或修改备注。
- 机器空间采用有限的区块强加载策略，并在节点失效或删除时释放票据。
- 集成核心和简单集成单元使用 Create 风格的横向传动轴动画；轴体使用官方 `axis` / `axis_top` 贴图，并保留两端各 0.5 像素的延伸。

## 方块

| 方块 | 用途 |
| --- | --- |
| 集成单元 | 大型多方块线路的核心，负责节点注册、结构识别和主世界应力映射。 |
| 简单集成单元 | 单方块节点，内置输入库存和输出库存，不需要多方块结构。 |
| 输入端口 | 访问节点的 27 格输入库存；主世界侧用于插入，机器空间侧用于取出。 |
| 输出端口 | 访问节点的 27 格输出库存；机器空间侧用于插入，主世界侧用于取出。 |
| 集成单元拓展接口 | 连接核心、端口并延伸多方块线路，不持有库存。 |
| 应力端口 | 将机器空间 Create 动力网络的应力需求映射回主世界。 |
| 基石 | 复制原版基岩的不可破坏属性，使用平滑石头外观，作为机器空间地面。 |

集成核心的左右两面是贯通的动力轴，简单集成单元同样如此。简单集成单元的正面是输入面，背面是输出面。普通空手右键用于进入机器空间；扳手右键交由 Create 的转向逻辑处理。

## 快速开始

1. 安装 Minecraft 1.21.1、NeoForge 21.1.x 和 Create 6.0.10。
2. 将模组 JAR 放入实例的 `mods` 文件夹。
3. 放置集成单元或简单集成单元，建立一个机器节点。
4. 在主世界连接输入/输出端口；大型结构还需要用拓展接口连接端口和核心。
5. 空手右键核心进入对应机器空间，在其中放置 Create 机器、传动结构和应力端口。
6. 向输入库存提供原料，从输出库存取走成品，并将应力端口接入有效的 Create 动力网络。

发布文件：[integrated_factory-2.5.1.jar](releases/integrated_factory-2.5.1.jar)

## 库存与自动化

每个节点固定拥有一份 27 格输入库存和一份 27 格输出库存。多个输入端口或输出端口不会扩展槽位，而是访问同一个逻辑库存。

端口通过 NeoForge `IItemHandler` 能力向漏斗、传送带和其他自动化设备提供接口，并按端口类型和所在维度限制插入/提取方向。玩家潜行右键端口时，可以打开对应的手动库存界面；潜行右键简单集成单元时，同时显示输入和输出两组库存。

## 多方块结构

大型线路使用六面连通搜索识别，结构必须满足：

- 恰好包含一个集成单元核心；
- 同一节点最多存在一个绑定主机核心；冲突核心会被移除并按其绑定状态掉落；
- 输入端口、输出端口和拓展接口只能归属于一个有效节点；
- 不同节点不会因为接口接触而自动合并；
- 结构数量受服务端 `maxStructureBlocks` 限制。

潜行右键集成单元可以查看结构统计，包括输入端口、输出端口、拓展接口和核心数量。

## 机器空间

所有节点共用隐藏的 `integrated_factory:factory_room` 维度，但每个节点使用互相隔离的空间区域。服务器端会限制边界、碰撞、流体和跨房间移动，进入时会寻找不会把玩家卡在方块里的安全落点。

机器空间支持多人协作。核心所在主维度区块未加载，或强加载额度不足时，远端工厂可能暂停加工；这用于避免主世界核心和远端动力网络脱节。

## Create 应力桥接

应力端口不读取应力表显示值，也不复制一个独立能量系统。它读取连接到该端口的 Create `KineticNetwork`，统计实际加载的动力消费者，并将远端负载映射为主世界核心的应力影响。

主世界核心过载、断开动力或节点失效时，远端虚拟动力容量会关闭，但设计负载仍保留用于结算，避免过载状态在远端停机后反复解除和重新触发。该功能依赖 Create 6.0.10 的内部动力网络 API，建议在目标整合包中进行实际应力回归。

## 常用命令

```text
/factory worlds
/factory enter <节点ID>
/factory note <节点ID> [备注]
/factory delete <节点ID>
/factory delete <节点ID> confirm
/factory inventory
/factory status
/factory allow <在线玩家>
/factory deny <在线玩家>
/factory return
/factory_return
```

`/factory worlds` 会列出当前玩家创建的节点，并提供可点击的进入、删除和备注操作。删除节点会释放强加载票据、删除节点库存和登记数据，但保留机器空间内部方块；主世界结构中的旧端口绑定会被清理，原核心会掉落为普通核心。节点删除前需要确认。

## 服务端配置

配置文件：`config/integrated_factory-server.toml`

| 配置项 | 作用 |
| --- | --- |
| `maxStructureBlocks` | 限制大型结构的最大连通方块数量。 |
| `maxRemoteStress` | 限制单节点可运行的远端应力负载；`0` 表示不限制。 |
| `roomFlight` | 是否允许玩家在机器空间内飞行。 |
| `maxForceLoadedChunks` | 所有机器空间可使用的强加载区块总额度；`0` 表示关闭。 |

## 已知限制

- 强加载受 `maxForceLoadedChunks` 总额度限制，额度不足时无人观察的机器空间可能卸载并暂停加工。
- 主维度核心区块未加载时，远端应力容量会关闭。
- 应力桥接依赖 Create 6.0.10 内部动力网络 API，跨大型整合包的兼容性仍需要实际测试。
- 协作者命令当前要求目标玩家在线。
- 旧存档中跨越多个区块的机器空间会按实际占用区块计算强加载额度。
