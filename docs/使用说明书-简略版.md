# Integrated Factory 简略说明书

适用版本：Integrated Factory 2.4.4；Minecraft Java 1.21.1；NeoForge 21.1.x；Create 6.0.10。

## 模组用途

本模组把 Create 工厂连接到一个隔离的机器空间。主世界中的核心、接口与库存负责组织物流和结算应力；机器空间中使用真实 Create 机器、配方和传动结构进行加工。所有机器节点共用 `integrated_factory:factory_room` 维度，但各自使用独立、相隔的 10×10×10 房间。

## 方块一览

| 方块 | 用途 |
|---|---|
| 集成单元 | 多方块结构核心；连接 Create 动力；保存节点并映射远端应力。 |
| 简单集成单元 | 单方块节点，带独立输入/输出库存，正面为输入、背面为输出、左右贯穿动力轴。 |
| 集成单元拓展接口 | 延伸或分支结构，不提供库存或动力。 |
| 输入端口 | 访问节点共享输入库存。 |
| 输出端口 | 访问节点共享输出库存。 |
| 应力端口 | 放在机器空间内，为远端 Create 网络提供受主世界核心约束的动力容量，并读取该网络应力。 |

## 快速使用

1. 在主维度放置集成单元，或放置简单集成单元。放置者成为节点所有者。
2. 大型结构用拓展接口连接输入端口、输出端口；结构只按六面相邻连接，且只能有一个集成单元核心。简单单元无需连接结构。
3. 使用扳手调整核心朝向；空手右键核心进入机器空间。机器空间初次进入时会生成房间。
4. 在机器空间搭建 Create 工厂，并将应力端口接到工厂的动力网络。机器空间内不能再放置集成核心或简单集成单元。
5. 在主世界端口蹲下右键打开对应的 27 格库存；机器空间端口蹲下右键访问同一库存。端口周围的自动化设备也可通过物品能力交互。
6. 使用 `/factory_return` 或 `/factory return` 返回进入前的位置与维度。

## 库存和自动化方向

每个节点只有一份 27 格输入库存和一份 27 格输出库存；多个相同类型端口共享库存。

- 主维度：输入端口允许插入；输出端口允许提取。
- 机器空间：输入端口允许提取；输出端口允许插入。
- 简单单元：正面是输入面，背面是输出面；左右面是动力轴面。其余面不提供自动化物品接口。

## 常用命令

| 命令 | 作用 |
|---|---|
| `/factory worlds` | 查看自己创建的节点，点击聊天中的进入、删除或备注操作。 |
| `/factory enter <节点UUID>` | 进入自己或获准协作者的机器空间。 |
| `/factory inventory` | 在机器空间打开输入与输出的合并库存界面。 |
| `/factory status` | 查看当前节点状态、远端应力和协作者数量。 |
| `/factory allow <玩家>` / `/factory deny <玩家>` | 节点所有者在机器空间内授权或撤销在线玩家。 |
| `/factory note <节点UUID> [备注]` | 所有者查询或修改备注，最多 128 个字符。 |
| `/factory delete <节点UUID>` | 发起删除确认；按聊天提示确认后删除节点数据。 |

## 机器空间、权限与加载

- 房间为一个共享维度中的隔离区域，不是每个节点各自注册一个 Minecraft 维度。
- 房间可建造范围为 10×10×10；服务器端限制玩家离开自己的范围及破坏/放置区域。
- `roomFlight` 默认开启；离开时恢复进入前的飞行权限、位置和视角。
- 每个新房间位于单个区块中。强加载受 `maxForceLoadedChunks` 总额度限制，默认 256；主核心所在区块未加载、节点失效/停用或额度不足时，远端加工可能暂停。
- 删除节点会释放其强加载并删除节点库存和登记数据，但保留机器空间里的方块；该操作不可通过本模组撤销。

## 当前边界

远端应力桥接使用 Create 6.0.10 的动力网络数据。编译成功不等于已完成所有 Create 附属模组和游戏内场景的兼容性回归；当前版本仍需在目标整合包中检查动力、房间朝向和自动化行为。
