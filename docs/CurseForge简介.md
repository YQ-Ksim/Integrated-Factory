# Integrated Factory

## 简介

Integrated Factory 是一个面向 Create 的 NeoForge 附属模组，将一套机械动力工厂封装为可管理的机器节点。主世界负责线路组织、共享库存和应力结算；隔离机器空间继续使用真实的 Create 方块、配方、物流和动力网络进行加工。

## 主要功能

- 10×10×10 的隔离机器空间，避免多个工厂相互干扰。
- 集成单元、简单集成单元、输入端口、输出端口、拓展接口和应力端口。
- 主世界与机器空间共享同一份 27 格输入库存和 27 格输出库存。
- 输入/输出端口支持 Forge `IItemHandler` 自动化接口，并保持方向性权限。
- 应力端口接入 Create 动力网络，按远端工厂的真实应力负载进行桥接。
- 支持机器节点所有权、协作玩家、备注、进入和删除管理。
- 节点绑定信息会随核心和简单集成单元掉落物保留。
- 机器空间提供有限区块强加载，并在节点失效或删除时释放票据。
- 使用 Create 官方轴体与截面贴图，核心传动杆保留两端 0.5 像素延伸。

## 依赖与版本

- Minecraft 1.21.1
- NeoForge 21.1.x
- Create 6.0.10

本模组不会替代 Create 的机器和配方，而是为现有 Create 工厂提供跨空间的组织、库存和应力桥接能力。

## 使用提示

先放置集成单元或简单集成单元，再在机器空间中布置 Create 工厂。输入端口用于供应原料，输出端口用于取出成品；应力端口必须接入有效的 Create 动力网络。详细命令、权限和故障排查请参阅项目中的《使用说明书-详尽版》。
